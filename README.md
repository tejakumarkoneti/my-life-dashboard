## 🎯 The Core Philosophy: Complete Lineage & Traceability

Never spend another day wondering if your hard work actually matters. Ascend connects everything together:

$$\textbf{Life Goal} \longrightarrow \textbf{Strategic Goal} \longrightarrow \textbf{Project} \longrightarrow \textbf{Daily Task} \longrightarrow \textbf{Schedule Block}$$

* **Goal Alignment Score**: Real-time metric measuring the percentage of daily actions directly compounding toward your high-level Life Goals.
* **Goal Alignment Tree (`HierarchyView`)**: An interactive lineage explorer allowing you to select any Life Goal and trace down into child projects, tasks, and calendar time-blocks, alerting you to orphaned tasks.

## ⚡ Main Sections & Capabilities

### 1. Dashboard
- **Daily Overview**: High-level summary of remaining tasks, habits, and momentum.
- **Active Focus Spotlight**: Highlight what you are currently executing with live timer integration.
- **Top Priorities**: Pinned critical tasks with instant checkoff.
- **Life Goals at a Glance**: Visual progress indicators for all core life domains.
- **Daily Habits Quick-Check**: Fast ritual completion.

### 2. Today
- **Prioritized Daily Todo List**: Filter by *All*, *Active*, *Top Priorities*, or *Completed*.
- **Currently Working On**: Dedicated spotlight banner with a live Pomodoro countdown timer.
- **Goal Alignment Pills**: Visual indicators showing which Life Goal and Project each task feeds into.
- **Quick-Add Bar**: Inline creation with priority (P1/P2/P3) and project linking.

### 3. Schedule
- **Interactive Daily Timeline**: Hourly visual time-blocking from morning to night.
- **One-Click Rescheduling**: Quickly shift blocks earlier or later (`-30m` / `+30m`).
- **Category Color-Coding**: Deep Work (Purple), Health (Green), Learning (Blue), Routine (Amber), Break (Teal), and Meetings (Rose).

### 4. Goals
- **Multi-Tiered Hierarchy**: Life Goals (5+ years), Long-Term (1-3 years), Short-Term (Quarterly), and Weekly Goals.
- **Interactive Progress Sliders**: Easily adjust completion percentages and track metric targets.
- **Project Counts**: See how many active projects feed each strategic goal.

### 5. Projects
- **Execution Engines**: Active project cards with milestone checklists.
- **Milestone Tracking**: Check off deliverables and see real-time progress meters.
- **Inline Milestone Creation**: Expand any project to add milestones on the fly.

### 6. Habits & Consistency
- **Daily Ritual Checklist**: One-tap completion with celebratory confetti.
- **Streak Counters**: Live tracking of current streaks (🔥) and all-time records (🏆).
- **14-Day Visual Heatmap**: GitHub-style activity grid for every habit.

### 7. Progress & Analytics
- **7-Day Task Velocity**: Interactive bar chart comparing daily output.
- **Habit Consistency Rate**: 7-day rolling completion percentage.
- **Category Time Distribution**: Analysis of Deep Work vs Routine vs Health hours.
- **Automated Insights**: Strategic observations based on your momentum.

### 8. Daily Journal & Reflection
- **Structured Retrospective**: 4 core prompts:
  1. *What I accomplished today*
  2. *What went well*
  3. *What needs improvement*
  4. *Key learnings & mental models*
- **Mood Tracker**: Select from ⚡ Energized, ✨ Productive, 🌱 Neutral, 💤 Fatigued, or 🌪️ Stressed.
- **Productivity Rating**: 5-star rating system with past entry history and notes.

## 🎨 UI & Modern Interactions

- **Dark / Light Mode**: Beautiful Zinc & Violet palette with persistent theme settings.
- **Global Command Palette (`⌘K` / `Ctrl+K`)**: Rapid search across all tasks, goals, projects, and shortcuts.
- **Quick-Add Anywhere (`Q`)**: Fast modal to create tasks, schedule blocks, goals, projects, or habits from any view.
- **Dockable & Fullscreen Focus Mode**: Pomodoro presets (25m Focus, 50m Deep Work, 5m Break) with sound and celebration feedback.
- **Zero-Setup LocalStorage Persistence**: All edits, checkoffs, and notes persist locally in your browser.
- **Reset to Sample Data**: One-click restore button in the sidebar to reset realistic initial data whenever needed.

```bash
# Clone the repository

# Navigate into project directory
cd life-dashboard

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
